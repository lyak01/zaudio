# zAudio

Reproductor de música local para Android — gratuito, sin anuncios, sin compras dentro de la app.

## Descargar

Descarga el APK más reciente desde la sección [Releases](https://github.com/lyak01/zaudio/releases).

## Características

- Reproducción de música local con cola de reproducción
- Ecualizador y amplificador integrados
- Letras sincronizadas y visualizador de audio
- Crossfade, efecto 8D y visualizador avanzado
- Playlists, favoritos, historial y exploración por artista/álbum/género
- Interfaz oscura/clara con colores de acento personalizables

## Requisitos

- Android 8.0 (API 26) o superior
- Permisos de acceso a archivos de audio

## Licencia y distribución

zAudio se distribuye como APK gratuito, sin anuncios, compras dentro de la app ni muros de pago.

- Puedes descargarlo, usarlo y compartirlo libremente.
- El código fuente no es público por ahora; el APK puede ser auditado libremente.
- No está permitido vender el APK ni presentarlo como producto propio.
- Las donaciones son completamente opcionales y no desbloquean nada: la app es 100% gratuita para todos.
